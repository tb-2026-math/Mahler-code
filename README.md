**Code for the paper "On the minimization of the Mahler area among planar convex bodies of constant width"**

1. Direct numerical optimisation method to solve the OCP (3.10) in Julia ; 

2. Generation and plot of a non-regular Reuleaux pentagon (and dual set) via Lemma 5.1 formula (5.5) in Maple (maple code .mpl and maple sheet .mw) ; 

3. Computation of the Santalo point for the non-regular Reuleaux polygon based on a newton's method (in python) ; 

4. Generation and plot of a non-regular Reuleaux heptagon (and dual set) via Lemma 5.1 formula (5.5) in Maple (maple code .mpl and maple sheet .mw) ; 

5. Computation of the Santalo point for a non regular Reuleaux heptagon based on a newton's method (in python).
