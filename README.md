Code for the paper "On the minimization of the Mahler area amongplanar convex bodies of constant width" : 

1. Direct numerical optimisation method (in Julia) ; 

2. Generation of non-regular Reuleaux pentagon (in Maple : maple code .mpl and maple sheet .mw) ; 

3. Computation of the Santalo point for the non regular Reuleaux polygon based on a newton's method (in python) ; 

4. Generation of non-regular Reuleaux pentagon (in Maple : maple code .mpl and maple sheet .mw) ; 

5. Computation of the Santalo point for a non regular Reuleaux heptagon based on a newton's method (in python).
